# LaunchPad — Job Seeker Website

A responsive job-seeker website prototype built with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive landing page
- Job keyword and location search
- Category cards that filter jobs
- Experience and work-type filters
- Save/unsave jobs in the current page session
- Demo profile/sign-in modal
- Empty state and clear-filters interaction
- Mobile navigation

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in a modern browser.

No build tools or package installation are required.

## Important
This is a front-end demo. The job listings, salary ranges, company names, and counts are illustrative, not verified vacancies. Sign-in, profiles, saving, and applying are not connected to a backend. To launch publicly, connect a database/API, authentication, real job feeds, and real application URLs.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — sample listings and interactions
